# Погода с тобой

Android-прототип персонального погодного виджета по ТЗ версии 1.0.

## Что уже работает

- варианты компоновки 2×2, 4×2 и 4×3;
- текущая погода для Берлина через Open‑Meteo без API-ключа;
- температура, ощущаемая температура, минимум/максимум дня;
- ближайшие осадки и четыре почасовые точки;
- локальный кэш при отсутствии сети;
- нажатие открывает экран приложения;
- автоматическое обновление не чаще чем раз в 30 минут;
- сборка APK в GitHub Actions.

Это первый устанавливаемый прототип. Выбор города, фото персонажа, AI-образы,
официальные предупреждения и полноценный экран настройки добавляются следующими этапами.

## APK

Откройте **Actions → Build Android APK → последний успешный запуск → Artifacts**
и скачайте `weather-with-you-debug`.
